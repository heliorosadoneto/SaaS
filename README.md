# SaaS Management System

Este é um projeto desenvolvido em [Next.js](https://nextjs.org/), criado para oferecer uma solução SaaS robusta para a gestão de empresas, produtos e clientes. Ele foi construído com [Prisma.io](https://www.prisma.io/) para modelagem e relacionamento eficiente de tabelas, permitindo a separação lógica de empresas e seus dados.

## 🚀 Funcionalidades do SaaS

- **Ponto de Venda (POS):** Gestão de vendas em tempo real para atender às necessidades do varejo.
- **Análise de Crédito:** Controle detalhado para avaliação de crédito dos clientes.
- **Gestão Financeira:** Monitoramento e planejamento financeiro completo.
- **Controle de Estoque:** Rastreamento e organização do inventário de produtos.
- **Carga e Descarga:** Registro de operações logísticas para maior eficiência.
- **Gestão de Frota:** Supervisão de veículos e otimização de entregas.

## 🛠️ Tecnologias Utilizadas

- **Framework:** [Next.js](https://nextjs.org/)
- **ORM:** [Prisma.io](https://www.prisma.io/) - Relacionamento entre tabelas e separação de dados por empresa.
- **Banco de Dados:** MySQL
- **Frontend:** TailwindCSS.
